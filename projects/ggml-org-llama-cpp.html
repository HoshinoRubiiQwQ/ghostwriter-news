最新摘要
**核心价值摘要**： `llama.cpp` 是一个纯 C/C++ 实现的 LLM 推理引擎，基于 ggml 张量库，支持 CPU 和 GPU 混合推理，无需 Python 或 CUDA 依赖。其核心优势在于极低的内存占用（量化至 4-bit 甚至 2-bit）和跨平台兼容性（x86/ARM/Apple Silicon），使 Llama、Mistral 等大模型能在消费级硬件上高效运行。项目通过持续优化内核（如 AVX2、NEON、Metal 后端）和量化策略，实现了接近 GPU 的推理速度，成为边缘部署和隐私敏感场景的首选方案。
