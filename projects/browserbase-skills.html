最新摘要
Browserbase Stargazers 是一个基于 Playwright 的自动化工具，用于批量抓取 GitHub 仓库的星标用户数据。它通过模拟浏览器行为绕过 API 限制，支持并发请求和断点续传，适合需要大规模分析项目受众的技术情报场景。核心价值在于低成本获取结构化用户列表，用于竞品分析或开发者社区研究。
